# Workspace Evidence Hub Tabs

## Purpose
- The workspace should not become one long report scroll.
- Upper sections handle judgment and action.
- The Evidence Hub holds the full evidence set behind stable tabs.

## Page Order
1. Property identity and summary decision hero
2. Highlights vs concerns
3. Proceed / what to do next
4. Evidence Hub tabs
5. Property chat

## Evidence Hub Tabs
- `Overview`
- `Visual`
- `Property`
- `Location`
- `Land & Planning`
- `Financial`
- `Documents`

## Tab Roles

### Overview
- Stage-aware summary
- Current focus
- Strongest supporting signal
- Main unknown to clear
- Highlights
- Concerns
- Key modules:
  - property facts
  - sale process and timing
  - planning constraints

### Visual
- Aerial / top-down image first
- Map and orientation second
- Listing detail images after context
- Rule:
  - context outranks staging

### Property
- Structural facts
- Condition and quality
- Defects and maintenance

### Location
- School fit
- Safety and crime posture
- Transport and walk times
- Street feel: traffic, quietness, light pollution, power lines
- Amenity: parks, retail, shopping, convenience
- Local hazards such as flood and bushfire

### Land & Planning
- Image-led parcel analysis, not a balanced two-column form
- Land value posture
- Subdivision potential
- Parcel / site image
- Width, depth, slope, and easement impact
- Zone, land use, council, and max height
- Detailed planning controls and implications

### Financial
- Unified market and pricing surface
- Guide price
- Estimated price range
- Estimated rent
- Estimated rental yield
- Median price trend
- Median rent trend
- Vacancy history
- Supply and demand pressure
- Recent sold comparables with photos, core facts, sold price, and sold date

### Documents
- Document interpretation
- Missing items
- Reference and provenance
- Raw completeness without first-screen attention theft

## Default Tab By Stage
- `Shortlisted` -> `Overview`
- `Reviewing report` -> `Property`
- `Ready for inspection` -> `Visual`
- `Needs further checks` -> `Documents`
- `Preparing offer` -> `Financial`
- `Under contract` -> `Documents`
- `Pre-settlement` -> `Overview`
- `Settled` -> `Overview`

## Visual Priority Rule
1. Aerial / top-down
2. Map / boundary / orientation
3. Floorplan
4. Listing detail imagery

This keeps the workspace grounded in buyer context rather than drifting back toward portal-style browsing.
