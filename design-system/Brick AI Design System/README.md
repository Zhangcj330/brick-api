# Brick AI Design System

Brick AI now follows an **Editorial Civic** direction: calm, evidence-aware, buyer-loyal, and warmer than a generic dashboard. The system is built to frame property decisions with judgment first, not marketing theatre.

## Foundations

- **Display serif:** Instrument Serif — used for verdict framing, heroes, and section headings
- **Body/UI:** Geist — used for controls, labels, chips, and product copy
- **Evidence mono:** IBM Plex Mono — used for excerpts, report references, and data-like text
