# Marketing UI Kit

Recreation of the public uber.com homepage in modular sections:

- `MarketingNav` — sticky white top nav with wordmark and primary nav links
- `Hero` — split: headline + tabbed "Request a ride / Drive & deliver" widget, with a pseudo-map preview
- `Suggestions` — three-up product tile row (Ride, Reserve, Intercity)
- `DriveStrip` — dark inverse section for driver acquisition with stat cards
- `Editorial` — three-up editorial cards (Business, Safety, Sustainability)
- `Footer` — dark four-column footer with wordmark

## Caveats

- All "imagery" is solid color blocks and basic SVG — Uber.com uses high-end photography and motion. Drop in real `<img>` tags or video for production.
- Copy is a direct match to Uber's voice patterns but is not lifted verbatim from uber.com.
